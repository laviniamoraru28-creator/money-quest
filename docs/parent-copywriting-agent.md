# Parent Communication & Copywriting Strategist

Generates four distinct editorial briefs each month for parents and carers. Topics rotate across financial education, entrepreneurship, leadership, decision-making and inclusive learning.

This free, offline MVP **does not generate finished articles**. It creates structured briefs for a human or separately authorized writing model, with editorial requirements, fact-checking and approval gates. It does not call paid APIs, post to social channels or publish to the website.

Run: `python3 scripts/parent_copywriting_agent.py`. Test: `python3 -m unittest discover -s scripts -p 'test_parent_copywriting_agent.py'`.
